# GeoPlay — Dossier de communication client

## Le pitch (30 secondes)

**GeoPlay transforme votre territoire en terrain de jeu.**
Nous composons avec vous une enquête géolocalisée sur mesure, qui se joue
**sans réseau** sur les téléphones des visiteurs : énigmes, orientation,
réalité augmentée, final spectaculaire. Vous repartez avec une attraction
réutilisable, pas un gadget jetable.

## 3 promesses

1. **Ça marche partout, même sans réseau.** Le jeu se télécharge avant (borne,
   QR, lien), puis fonctionne à 100 % offline : carte, énigmes, boussole, AR.
2. **C'est votre histoire, pas notre gabarit.** Lieux, récit, visuels, difficulté
   (enfant/famille/expert), modes animateur : tout se configure dans notre Studio.
3. **C'est fiable le jour J.** Tirage équitable et rejouable, triche de test
   tracée, parcours de secours si GPS faible, capteurs en panne ou soleil aveuglant.

## Chiffres repères

- 100 % offline après téléchargement (pack vérifié fichier par fichier).
- 1 seule fenêtre de jeu à la fois : jamais de pop-ups empilées.
- 5 modules : quiz, 7 erreurs, puzzle, boussole, réalité augmentée (+ extensible).
- 2 entrées de test : dans l'app et dans le Studio, sans toucher au terrain.

## Comment ça marche

```
1. COMPOSER (Studio, avec vous) --> 2. TÉLÉCHARGER (borne/QR) --> 3. JOUER (terrain, offline)
   graphe + récit + visuels           pack vérifié                   énigmes + final
```

## Démo : « Lupin et l'Aiguille » à Étretat (~1 h, famille)

> Clin d'œil à Arsène Lupin (Maurice Leblanc, domaine public). Lieux publics,
> coordonnées d'exemple.

**L'histoire.** Lupin a semé 5 indices autour d'Étretat. Le hasard en désigne un
premier : falaise d'Aval (quiz), sentier d'Amont (boussole), jardins (puzzle),
marché (7 erreurs), chapelle (quiz chronométré). Chaque indice résolu rapproche
de la révélation : **l'Aiguille, en réalité augmentée** face à la mer.

**Storyboard visiteur.**

```
Belvédère : "Lupin vous salue" --> tirage d'un indice --> marche terrain (flèche + carte offline)
--> énigme (modale unique) --> indice résolu --> rendez-vous à l'Aiguille --> révélation AR --> score
```

**Ce que la démo prouve.** Tirage 1/5 équitable et persisté ; jeu fluide même si
le GPS saute (sortie de zone sans perdre sa partie) ; quiz lisible en plein soleil
(texte + haptique, jamais couleur seule) ; final AR avec plan B 2D ; animateur
capable de forcer un indice pour une démo presse (traçabilité triche).

## Questions fréquentes

- **Et sans réseau ?** C'est le principe : tout est dans le pack vérifié.
- **Et si le GPS est mauvais ?** Rayons réglés par lieu, temporisation anti-faux-positif,
  parcours conservé hors zone, mode animateur en dernier recours.
- **Et la batterie ?** Cartes pré-chargées, capteurs sobres, sessions d'1 h calibrées.
- **Et la triche ?** Les tests sont marqués et séparés des scores terrain.
- **Et nos données ?** Positions traitées sur l'appareil ; contenus et licences
  tracés (fournisseur, droits) ; statuts de relecture avant publication.
- **Et après l'événement ?** Le jeu se rejoue (nouveau tirage), se traduit, se décline
  (soirée, experts, scolaires).
